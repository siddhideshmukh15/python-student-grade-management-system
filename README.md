# 🎓 Grade Management System (Python)

A simple command-line **Grade Management System** built using Python. This project allows users to manage student grades by adding, updating, deleting, and viewing records. It is a beginner-friendly project that demonstrates the use of Python dictionaries, functions, loops, and conditional statements.

## ✨ Features

* ➕ Add a new student and grade
* ✏️ Update an existing student's grade
* 🗑️ Delete a student record
* 📋 Display all student grades
* 🚪 Exit the application

## 🛠️ Technologies Used

* Python 3

## 📂 Project Structure

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or your terminal.
4. Run the program:

```bash
python grade_management.py
```
